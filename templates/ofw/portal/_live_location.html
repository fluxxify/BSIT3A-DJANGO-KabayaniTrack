{% comment %} Continuous OFW location sharing for every portal page. The browser can only read GPS while a KabayaniTrack page is open, so this partial is loaded once from ``theme/base.html`` instead of only on the location page. That way an OFW can browse concerns, check-ins or their profile and their position keeps streaming to the agency. Closing the browser (or swiping the app away) still stops updates — no web page can keep the GPS alive after it is closed. Points captured while offline are queued in localStorage and replayed when the device reconnects, so a short signal loss does not leave a hole in the map. {% endcomment %} {% if live_location_enabled %} {% endif %}
